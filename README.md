# منصّة القبض — تطبيق أندرويد

تطبيق أندرويد (WebView) يفتح «منصّة القبض · الدفع الإلكتروني الموحّد» من:
https://ikraakhemis-maker.github.io/epaimen/

مبني على نفس مشروع تطبيق «طبيب خميس مليانة» مع تغيير الرابط والاسم والأيقونة فقط.

## الميزات
- أيقونة تكيفية (Adaptive) تدعم أيقونات Android 13+ المتناسقة، وشاشة بداية
- سحب للأسفل للتحديث، شريط تحميل، وشاشة «لا يوجد اتصال» مع إعادة المحاولة
- أزرار الاتصال الهاتفي (tel:) وواتساب والروابط الخارجية تُفتح في تطبيقاتها
- زر الرجوع يتنقل داخل الموقع

## الحصول على APK
1. أنشئ مستودعاً جديداً على GitHub وارفع كل الملفات إليه (فرع `main`).
2. تبويب **Actions** ← **Build Android APK** ← انتظر الاكتمال.
3. نزّل `Epaimen-APK` من **Artifacts**، فك الضغط، وثبّت `app-debug.apk`.

## التخصيص
- رابط الموقع: `TARGET_URL` و`HOST` في `app/src/main/java/com/epaimen/app/MainActivity.java`
- الاسم: `app/src/main/res/values/strings.xml`
- معرّف الحزمة: `com.epaimen.app` في `app/build.gradle`
